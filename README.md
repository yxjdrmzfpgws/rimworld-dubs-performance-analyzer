## Overview

Dubs Performance Analyzer adds a runtime profiling overlay to RimWorld that measures the per-tick CPU cost of every loaded mod method, displaying results in a sortable table and historical graph. It is the standard tool used by both modders diagnosing their own code and players identifying which installed mods are causing late-game FPS drops.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Dubs Performance Analyzer** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Real-Time Profiling** | Live CPU cost measurement per mod and method during active gameplay |
| **Per-Mod Breakdown** | Shows exactly which mod's update loop consumes the most CPU time |
| **Sortable Table** | Sort all tracked methods by absolute cost, relative cost, or call count |
| **Historical Graph** | Per-method CPU cost graph plotted over tick history |
